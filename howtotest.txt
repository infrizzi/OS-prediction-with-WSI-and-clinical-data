To test, first set the right test path inside every testing file inside "scripts" directory, then:

- Clinical unimodal -> pretty straightforward, paths are already set (test_unimodal_clinical.py)

- Clinical visual -> same (test_wsi_abmil/transmil.py)

- Multimodal -> some changes depending on the specific test; 
                for ABMIL vesrion use file "test_MCAT.py", while for TransMIL use file "test_MCAT_trans.py". 
                They share same steps:
                1. Visual as Query
                    a. Set "src.models.cross_attention_VaQ import CrossAttention" in the imports
                    b. Select the model path to test inside "outputs/checkpoints/abmil" or "outputs/checkpoints/transmil"
                    (be sure to pick the VaQ models) changing "MCAT_CKPT_DIR". Depending on the model chosen, you need
                    change something as follows in the next steps

                    c. mcat_VaQ_concat: inside "cross_attention_VaQ" de-comment "Final projection" and "4. Concatenation",
                    then write "out = self.norm(vis_x + self.out_proj(combined))" in "5. Final projection + Residual".
                    Finally, check inside file "MCAT.py" in the function "compute_visual_path" if "2. ABMIL" is de-commented,
                    also check "vis_emb, cross_attn_weights, abmil_attn" is the right output
                    
                    d. mcat_VaQ_noconcat_frozen: inside "cross_attention_VaQ" comment "Final projection" and "4. Concatenation",
                    then write "out = self.norm(vis_x + context)" in "5. Final projection + Residual". Finally, check inside 
                    file "MCAT.py" in the function "compute_visual_path" if "2. ABMIL" is de-commented, also check 
                    "vis_emb, cross_attn_weights, abmil_attn" is the right output

                    e. mcat_VaQ_noconcat_full: same as frozen


                2. Clinical as Query
                    a. Set "src.models.cross_attention_CaQ import CrossAttention" in the imports
                    b. Select the model path to test inside "outputs/checkpoints/abmil" or "outputs/checkpoints/transmil"
                    (be sure to pick the CaQ models) changing "MCAT_CKPT_DIR" 
                    c. Go inside file "MCAT.py" in function "compute_visual_path" comment "2. ABMIL", changing
                    output in "vis_guided.squeeze(1), cross_attn_weights, None"

                    d. mcat_CaQ_noresidual: inside "cross_attention_CaQ" comment "self.clinical_proj", "residual" and 
                    "5. ABMIL aggregation". Then write "out = self.norm(context)" and check Q projection inside
                    forward takes "clin_emb"

                    e. mcat_CaQ_clinicresidual: inside "cross_attention_CaQ" de-comment "self.clinical_proj" and change
                    self.q_proj into "self.q_proj = nn.Linear(d_model, d_model)". Then, de-comment "residual" and
                    change Q projection inside forward taking "residual" instead of "clin_emb". Finally, write
                    "out = self.norm(context + residual)" 

                    f. mcat_CaQ_wABMIL: inside file "MCAT.py" in function "compute_visual_path" write as output
                    "vis_guided, cross_attn_weights, None". Inside "cross_attention_CaQ" comment "self.clinical_proj"
                    and "residual", checking Q projection inside forward takes "clin_emb". Then, de-comment "5. ABMIL"
                    and write "out = self.norm(context + abmil_emb)"
